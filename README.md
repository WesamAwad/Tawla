# Tawla Menu 🍽️

**Tawla Menu** قائمة طعام رقمية تساعد الزبائن على تصفح أطباق المطعم بسهولة من جوالهم، بدون الحاجة لقائمة ورقية.

## المميزات

- تصفح الأطعمة والمشروبات مقسّمة حسب الأصناف.
- عرض تفاصيل كل طبق مع الصورة والسعر والوصف.
- واجهة بسيطة وسريعة تعمل على الجوال والكمبيوتر.
- لوحة تحكم لإدارة القائمة وتحديثها بسهولة.

## التقنيات المستخدمة

Laravel · React · Inertia.js · Tailwind CSS
